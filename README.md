# Stock Lens

A one-page stock research tool for everyday investors. For any company, Stock Lens
pulls together business model, financial health, competitive moat, valuation,
bull/bear case and analyst consensus into a single, consistently structured page —
every figure shown with its source and the date it was checked.

> Built for the BBC Champion Sprint challenge. See [`docs/`](./docs) for the
> discipline evidence pack (Product, Agile, UX/UI, Security, Testing) and
> [`docs/api-schema.md`](./docs/api-schema.md) for the API contract.
