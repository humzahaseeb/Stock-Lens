# Stock Lens — API Response Schema

`GET /api/company/:ticker` returns one JSON object: a one-page company summary.
Metrics and narratives include source/date metadata where available. Synthetic
worked-example fields identify themselves as demo data; those values are
illustrative, not actual company financials.

## Field provenance — what's real/live vs manual, and why

| Section | Source | Notes |
|---|---|---|
| `ceo` | **Financial Modeling Prep** (company profile) | Sent as a top-level field and displayed in the Business model section; `ceoSource` and `ceoAsOf` identify its provenance. Requires a successful live FMP response or a seeded snapshot. |
| `marketCap` | **FMP live/seed or labeled synthetic overrides** | Sent as a top-level, formatted value and also shown in `valuation.metrics`; NVDA and RR.L demo overrides use the same synthetic value in both places. |
| `peRatio`, `eps`, `quarterlyDividend` | **Manual company override or seeded snapshot** | Optional top-level values retained in the API; the page displays the corresponding metrics in the Valuation section instead of duplicating them beside the CEO. |
| `financialHealth` | **FMP live/seed or labeled synthetic overrides** | NVDA and RR.L use explicitly flagged synthetic demo metrics. For other symbols, FMP supplies revenue, net profit margin, debt/equity, current ratio, and trailing free cash flow summed from the latest four quarterly cash-flow statements. If FCF is unavailable, a note is surfaced rather than fabricating it. |
| `financialHealth.demoData`, `demoNote` | **Synthetic NVDA/RR.L metrics** | `demoData: true` groups the synthetic source/date into a single footer at the bottom of Financial health. |
| `financialHealth.note` | **Optional FMP error detail** | Explains why free cash flow could not be fetched when no existing/seeded FCF metric is available. |
| `financialHealthSource` | **Financial health provenance** | Reports `live`, `seed-cache`, `unavailable`, or `demo-data` independently of valuation's `financialsSource`. |
| `valuation` | **FMP live/seed or labeled synthetic overrides** | NVDA and RR.L use explicitly flagged synthetic demo values, including Forward P/E and EV / EBITDA. Other tickers use FMP price, P/E (TTM), EPS, market cap, Forward P/E when present in the quote, and EV / EBITDA from `enterpriseValueMultiple`. Missing ratios are omitted with an explanatory note, not estimated. |
| Displayed current price in Valuation and analyst forecast | **Yahoo Finance chart quote after load** | The frontend reuses one chart quote for both sections so the price and forecast baseline agree. In demo-valued sections, the Yahoo quote and its date are shown inline while synthetic metrics retain the single synthetic footer. If the quote is unavailable, the sections use available summary/override values. |
| `valuation.demoData`, `demoNote` | **Synthetic NVDA/RR.L metrics** | `demoData: true` groups the synthetic source/date into a single footer at the bottom of Valuation. |
| `valuationSource` | **Valuation provenance** | Reports `live`, `seed-cache`, `unavailable`, or `demo-data` independently of the broader financials source. |
| `incomeStatements.annual`, `incomeStatements.quarterly` | **FMP live/seed or labeled synthetic overrides** | Requests up to five annual and four quarterly statements; each period can fall back to a seeded snapshot. NVDA and RR.L use explicitly flagged synthetic override data for the demo. API failures are surfaced in that period's `error` field. |
| `incomeStatements.*.demoData`, `demoNote` | **Synthetic NVDA/RR.L chart data** | Marks the figures as synthetic in the response; the chart shows the source and date in its footer. |
| `analystConsensus` | **Manual override or Finnhub** (live, free tier — `/stock/recommendation`) | NVDA uses the analyst counts supplied in the Google Finance screenshot; RR.L uses explicitly labeled synthetic demo data. Curated overrides take precedence over live data. Otherwise, ratings are derived from Finnhub's buy/hold/sell/strongBuy/strongSell counts. **Free-tier coverage is US-market-focused** — for `RR.L`, Finnhub is queried using the US ADR `RYCEY` when no curated override applies. `consensusSource` reports `manual-override` or `demo-data` accordingly. |
| `analystConsensus.demoData`, `demoNote` | **Synthetic Rolls-Royce demo fixture** | `demoData: true` marks the synthetic consensus in the API; the UI displays its “Synthetic demo data” source/date footer. Synthetic consensus is excluded from bull/bear derivation. |
| `analystConsensus.priceTarget12m` | **Manual override for NVDA; synthetic demo value for RR.L; no free automated API verified** | NVDA's 12-month targets were entered from the user-provided Google Finance screenshot. RR.L's targets are fabricated for UI demonstration. The UI shows source/date; presenters must disclose values are synthetic where applicable. Other symbols remain unavailable unless verified target data is added. Finnhub's `/stock/price-target` endpoint requires a paid plan. |
| `analystConsensus.priceTargetHigh`, `priceTargetLow`, `priceTargetAnalystCount`, `priceTargetSource`, `priceTargetAsOf` | **Optional manual/seed/demo data** | The forecast card displays a high/average/low range, target analyst count, and source/date when supplied. |
| `insiderSentiment` | **Finnhub** (live, free tier — `/stock/insider-sentiment`) | Finnhub's own docs state this covers **US companies only**; returns `null` for symbols with no data (e.g. most non-US tickers) rather than erroring. Optional supporting signal, not a required section in the UI. |
| `bullCase`, `bearCase` | **Precedence chain**: human-curated override → auto-derived from live data (`backend/src/lib/deriveBullBear.js`) → placeholder | Real, human-researched content (`needsResearch: false` in the override file) always wins — it's richer than the heuristic rules below. If there's no human content yet, fixed, explainable rules turn real numbers (margins, leverage, liquidity, valuation, analyst consensus, insider sentiment) into bullet points (`autoGenerated: true`), since no free API provides genuine analyst-written bull/bear thesis prose. If neither exists, falls back to the `needsResearch: true` placeholder. Human content that's missing a verifiable citation is marked `sourcePending: true` with an `aiDeclarationNote` rather than a fabricated source — see `backend/src/routes/company.js`'s `pickNarrative()`. |
| `businessModel`, `competitiveMoat` | **Manually curated**, per company (`backend/src/data/overrides/*.json`) | These are genuinely qualitative/analytical judgment calls (how a business makes money, why its moat holds up) — no free (or paid, realistically) API returns this as structured data. Each entry is dated and sourced by hand, and marked `aiAssisted` for the AI declaration. |

## Live stock chart endpoint

`GET /api/company/:ticker/stock-chart?range=1d` returns:

```json
{
  "ticker": "NVDA",
  "range": "1d",
  "currency": "USD",
  "exchangeTimezone": "America/New_York",
  "asOf": 1794243463,
  "currentPrice": 176.495,
  "previousClose": 186.64,
  "change": -10.145,
  "changePercent": -5.435,
  "points": [{ "time": 1794234600, "close": 176.495 }],
  "source": "Yahoo Finance",
  "delayNote": "Market data may be delayed; this public feed is not guaranteed real-time."
}
```

The app's public Rolls-Royce ticker is `RR`; it maps internally to the LSE
Yahoo/FMP symbol `RR.L` (the legacy `RR.L` app route remains accepted).
The chart UI labels Yahoo's `5d` range as `5D`; its x-axis shows day/date
labels instead of intraday times for this range.
Supported `range` values are `1d`, `5d`, `1mo`, `6mo`, `ytd`, `1y`, `5y`, and
`max`. The 5D and 1M ranges both use daily price sampling for a less jagged line;
1D uses intraday samples. Intraday requests are cached for about one minute;
longer ranges are cached longer to reduce upstream traffic. The public Yahoo
Finance feed can be delayed and is not guaranteed real-time. For `1d`, change
is measured against previous close; longer ranges compare with the first
returned chart point.
The chart displays the source and quote timestamp in a footer below the chart
and statistics.
After the chart quote loads, the frontend uses that same quote for the current
Price shown in Valuation and for the current-price baseline in the 12-month
forecast. If the chart request fails, both fall back to their available
summary/override price.

See `docs/data-seeding.md` for how live data is pinned (cached) for demo reliability, and `docs/security/risk-register.md` for why price targets and bull/bear narrative are handled this way rather than guessed.

## Error responses
`GET /api/company/:ticker` returns `404` with `{ "error": "..." }` if the ticker is
unknown to both FMP and the manual overrides, and `400` if the ticker fails input
validation (must be 1–10 uppercase letters/dots, e.g. `NVDA`, `RR.L`).
For Rolls-Royce, use the public app ticker `RR`; `RR.L` remains a supported
legacy alias and the underlying LSE data-source symbol.
